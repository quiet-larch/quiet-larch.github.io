Privacy Policy

Last updated: October 6, 2026

Family Ops is a private tool used by a single household. It is not offered to anyone else.

What it accesses

  • Gmail (read-only): messages in the owner's own inbox that come from school senders or mention school keywords. It cannot send, delete, or modify email.
  • Google Calendar: one family calendar, used only to create events that a parent has approved.

How data is used

Matching emails are summarized and sorted using the Anthropic Claude API, and the summaries are posted to the family's private Discord server. Email content is not used for advertising, is not sold, and is not shared with anyone outside the household except the service providers needed to run the tool (Google, Anthropic, Discord).

Storage and retention

A small log (sender, subject, short summary, and processing status) is kept on the owner's own computer to avoid processing the same email twice. Full email bodies are not stored.

Google API data

Family Ops' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact
